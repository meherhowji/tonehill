# ToneHill

A mobile app to help you refine your singing by tracking pitch accuracy and
other vocal metrics in real time.

Built with **React Native**, **D3**, and **Skia**.

## Features

- Real-time pitch detection and accuracy tracking
- Visual feedback rendered with Skia
- Metric visualisation powered by D3

## Getting Started

```bash
npm install
npm start        # start Metro bundler
npm run ios      # or: npm run android
```

> Requires the [React Native environment setup](https://reactnative.dev/docs/environment-setup).
